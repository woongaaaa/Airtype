테스트 중 동반 움직임을 포함한 합성 자료에서 손가락 후보 선택을 확인했다. 테스트 fixture에서 엄지까지 같이 움직이던 조건을 분리하고, 후보 강도가 비슷한 경우 임의의 키를 출력하지 않는 회귀 테스트를 추가했다.

## 환경 문제와 해결

- Xcode는 설치되어 있으나 라이선스 동의 미완료. 정상 동작하는 별도 Command Line Tools로 빌드했다. 사용자 대신 동의하지 않았다.
- 현재 CLT의 SwiftPM 기본 빌드 경로와 Testing.framework 탐색 경로 차이를 우회하기 위해 native build system과 명시적 테스트 프레임워크 경로를 사용한다. 해당 옵션의 deprecation 경고가 있으므로 향후 툴체인 업데이트 시 재검토한다.
- iCloud 작업 폴더에서 editable 설치의 `.pth`가 hidden 속성으로 저장되면 Python이 경로를 무시한다. 연구 명령은 `--no-editable`로 일반 wheel을 설치하며 소스 파일을 cache key에 포함한다.
- MediaPipe가 의존하는 opencv-contrib-python과 별도 opencv-python의 파일 충돌을 피하도록 단일 wheel로 정리했다.

## 아직 검증하지 않은 항목

실제 손/양손 가림/거리/조명, 카메라 권한 부여, 손가락 보정의 충분성, 10 WPM와 5% CER, 한글 조합·삭제·실제 앱 단축키, 실제 드래그·스크롤, 잠자기/복구, 다른 Mac·이전 OS 설치, 외부 사용자 5명, 서명·공증은 미완료다.

Vision은 기준 구현이다. MediaPipe와의 실제 손 영상 비교 결과 없이 최종 선정했다고 주장하지 않는다. MediaPipe helper 제품 통합은 ADR의 조건이 충족될 때만 진행한다. 출시 gate는 false를 유지한다.
