## 문제와 대상

대상은 **일반 PC 사용자**이며 첫 플랫폼은 macOS이다. 키보드가 고장났거나 없거나, 손이 더럽거나, 키보드에서 떨어져 있을 때 짧은 문자 입력과 화면 조작을 수행한다. 개발 도구·터미널 사용 능력을 요구하지 않는다. 장시간 물리 키보드 대체와 의료용 보조기기 인증은 목표가 아니다.

## 확정된 요구사항

| ID | 요구사항 | 검증 |
|---|---|---|
| K01 | 표준 QWERTY 위치 관계의 양손 열 손가락 입력 | 일반 문장·숫자·기호 과제 |
| K02 | 한글 두벌식과 영문, 한영 전환 | TextEdit·Safari·Chrome에서 조합·삭제·전환 |
| K03 | 공백·삭제·Enter·Tab·Esc·방향키·숫자·기호 | 고정 회귀 과제 |
| K04 | Shift·Command·Option·Control을 다음 키에 적용 | 대문자·기호·복사·붙여넣기·실행 취소 |
| P01 | 이동·클릭·더블클릭·우클릭·드래그·스크롤 | 표적·드래그 과제 |
| P02 | 브라우저 뒤로·앞으로 | Safari·Chrome 탐색 |
| U01 | 손 위치 안내와 개인 보정 | 외부 사용자 설정 3분 이내 |
| U02 | 설정 이후 물리 키보드 없는 모드 전환·정지·수정 | 한 세션의 시작부터 종료까지 과제 |
| S01 | 추적·카메라·세션 중단 시 새 입력 차단과 버튼 해제 | 재생 테스트 + 실기기 중단 시험 |
| S02 | 복구 후 준비 상태, 자동 입력 재개 금지 | 상태 전이 테스트 |
| D01 | 개발 도구 없는 Mac에서 DMG 설치 | 최소 2종 Apple Silicon Mac |
| D02 | 로컬 처리, 기본 녹화·업로드 없음 | 코드 검토 + 네트워크 사용 점검 |

물리 키보드처럼 모든 손가락을 동시에 독립적으로 누르는 게임용 N-key rollover는 범위 밖이다. 문자를 순차 입력하며, 약지·새끼손가락을 포함한 열 손가락의 역할을 검증한다. 엄지는 공백, 다른 손가락은 누름 시작 위치의 키를 선택한다. 화면 키를 마우스로 클릭하는 대체 입력기로 바꾸지 않는다.

최초 설치와 macOS 권한 부여는 기존 마우스·트랙패드를 사용할 수 있다고 가정한다. 권한 설정 없이 앱이 macOS를 조종할 수 있다는 약속은 하지 않는다.

## 성공 시나리오

1. 손이 오염된 사용자가 준비된 앱을 활성화해 짧은 검색어를 입력하고 결과를 스크롤한다.
2. 키보드가 고장난 사용자가 한영 전환과 삭제를 이용해 짧은 메시지를 완성한다.
3. 떨어진 사용자가 포인터·스크롤·브라우저 탐색을 수행하고 다시 정지한다.
4. 손이 카메라에서 사라져도 드래그가 남지 않으며, 다시 준비하고 작업을 이어간다.

## 출시 합격 기준

- 영문: 수정 시간을 포함한 10 WPM 이상, 자동 교정 전 CER 5% 이하.
- 한글: 키 이벤트 오류율 5% 이하. 최종 조합 문자열 CER를 별도로 보고하고 조합·받침·삭제·한영 회귀 과제 통과.
- 포인터: 사전 고정한 과제 성공률 95% 이상.
- 오입력: 활성 상태의 비입력 과제에서 10분당 키·클릭 1회 이하.
- 복구: 추적 상실·카메라 오류·잠자기·정상 종료에서 눌린 버튼 잔류 없음.
- 지연: M3 Pro에서 프레임 수신→이벤트 발행 p95 100ms 이하. 물리 움직임→화면 지연으로 표현하지 않는다.
- 사용성: 초기 안내·보정 3분 이내, 10분 연습 후 과제 가능, 10분 사용 불편감 4/10 이하.
- 개발자 외 5명·최소 2종 Mac. 사용자별 결과를 보고하고 최소 4명이 핵심 기준을 충족해야 한다.
- 공증된 DMG의 다른 Mac 설치·권한 설정·재실행 통과.

## 운영 범위와 비목표

카메라–손 거리 목표: 타이핑 40~80cm, 포인터 1~2m. 카메라에 맞춘 기울임·공중 자세를 허용한다. 일반 실내 조명에서 평가하며, 저조도·역광·가림은 무조건 입력하기보다 정지·안내를 우선한다. 단일 화면·Apple Silicon·로그인된 세션부터 검증한다. macOS 14 이상을 목표로 하되 실제 검증 범위만 배포 문서에 보장한다.

첫 버전에서 로그인/잠금 화면, 모든 앱 호환, 게임·미디어키, 다중 모니터, Intel, Windows, 앱스토어, 자동 업데이트, 대규모 모델 학습, 언어모델 자동 교정은 제외한다.
