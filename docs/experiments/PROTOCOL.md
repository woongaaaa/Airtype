# 실험 프로토콜 v1

## 원칙

기술 검증과 출시 평가를 구분한다. 성공한 본인 영상만 골라 보고하지 않는다. 보정/튜닝 세션과 평가 세션을 분리하며 동일 문장을 반복 학습한 결과를 일반화 성능으로 제시하지 않는다. 원본 영상·문자 입력은 실험 참여자가 명시적으로 제공한 자료만 사용한다.

현재 참가자는 개발자뿐이다. 외부 5명과 다른 Mac 확보 전에는 일반 사용자용 출시를 승인하지 않는다. 참가자 ID는 가명으로 부여하고 원본 데이터·이름·얼굴·입력 문장은 GitHub에 업로드하지 않는다. 공개 가능한 요약 지표나 재배포 동의가 있는 자료만 별도로 검토한다.

## 장비·환경 기록

기기 모델, OS, 카메라 해상도/프레임률, 화면 크기/배율, 카메라–손 거리, 조명 조건, 좌/우손, 자세, 코드 커밋, 엔진·모델 버전·SHA-256, 보정 프로필 버전을 세션 manifest에 기록한다. 40/60/80cm 타이핑과 1/1.5/2m 포인터를 별도 조건으로 평가한다. 거리별 실패를 평균으로 숨기지 않는다.

## 평가 순서

1. 원본 손 영상의 회전과 좌우 라벨을 확인한다. 왼손/오른손을 각각 들어 기준 라벨을 만든다.
2. 보정 세션에서 홈 위치·손가락별 임계값을 정한다. 평가 세션 중 정답을 보고 수정하지 않는다.
3. 기본 키/행 이동 과제: 26자, 숫자, 기호, 공백, 삭제·Enter·Tab·방향키를 포함한다.
4. 영문 20개 짧은 문장과 한글 20개 짧은 문장을 타이핑한다. 문장 목록과 순서는 평가 전에 고정하고 보정 자료에 포함하지 않는다.
5. 숫자·기호 혼합 10개 과제, 대문자·복사·붙여넣기·실행 취소·한영 전환을 수행한다.
6. 10분 비입력 과제에서 손 유지·자세 변경·얼굴 만지기·프레임 출입을 수행한다.
7. 포인터 과제는 화면 내 44×44pt 표적 40회 선택, 더블클릭 10회, 우클릭 10회, 80pt 드래그 표적 10회, 스크롤 10회, 브라우저 탐색 10회로 고정한다. 화면 크기·배율을 보고한다.
8. 카메라 중지, 권한 해제, 다른 앱으로 포커스 전환, 손 가림, 프레임 중단, 잠자기/복귀를 시험한다.
9. 설정 시간, 10분 연습 후 과제 수행 여부, 10분 사용 후 0~10점 불편감을 기록한다.

## 측정 정의

- 영문 WPM = NFC 정규화한 최종 문자열 길이(공백 포함) / 5 / 분. 수정 시간 포함. 최종 CER도 함께 보고하여 잘못된 문자를 많이 입력해 속도를 높인 결과를 드러낸다.
- Raw CER = 정답과 수정 전 인식 문자열의 Levenshtein 거리 / 정답 문자 수. 누락·중복·오자를 포함하고 100%를 넘더라도 자르지 않는다.
- 최종 CER = 사용자 수정 이후 결과에 같은 계산을 적용한다.
- 한글: 완성형 NFC 문자열 CER와 기대 키 이벤트 시퀀스의 오류율을 분리한다. 한글 속도를 영문 WPM으로 직접 비교하지 않는다.
- 빈 정답은 CER로 처리하지 않고 비입력 과제의 오입력 횟수로 계산한다.
- 누름 이벤트 precision/recall/F1: 같은 키·±150ms, 순서 유지, 일대일 대응. 한 예측을 여러 정답에 대응시키지 않는다.
- 실시간 처리 지연: 프레임 콜백 수신부터 OS 이벤트 발행까지. 추론 단독 시간, 오프라인 영상 처리 시간, 물리 움직임→화면 지연과 구분한다.
- 참가자별 중앙값·p95·실패율을 보고한다. 프레임 개수를 독립 사용자 수처럼 다루지 않는다.

현재 앱 UI의 ms는 **최근 한 프레임 처리 시간**이며 p95 계측 결과가 아니다. 실제 출시 지연 평가는 별도 세션 자료가 필요하다.

## 동일 조건 엔진 비교

동일 upright/unmirrored 영상 → VisionExport/MediaPipe export → 같은 HandFrame → 같은 Swift replay → 같은 정답 이벤트/문장 지표. 같은 보정 방식과 동일 고정 임계값 비교를 먼저 수행한다. 엔진별 튜닝을 허용한 비교는 별도 표로 분리하고 튜닝 시간을 함께 기록한다.

3D 값을 쓰는 알고리즘과 2D 알고리즘을 섞어서 단순히 '엔진이 더 정확하다'고 결론 내리지 않는다. 모델 지연이 짧아도 키 입력 오류가 높으면 채택하지 않는다.

## 중단·출시 판단

2주차 기본 키 오류율 10% 이하와 5분 비입력 1회 이하가 최소 제품화 근거이다. 불합격이면 3~4주차를 인식 개선으로 전환한다. 최종 조건은 [PRD](../PRD.md)와 [출시 문서](../RELEASE.md)를 따른다. 합성 데이터의 통과 결과는 실사용 합격 근거에서 제외한다.
